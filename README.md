Site de portfólio de Vinicius Marrara: https://vinimarrara.github.io/

## Como adicionar um projeto
A seção **Projetos** se monta sozinha a partir do GitHub. Para um projeto novo aparecer:

1. Crie um repositório com o `index.html` do painel e ative o **GitHub Pages** (Settings → Pages → branch `main`).
2. Coloque um `preview.png` (1200×750) na raiz do repositório.
3. Em **About** (engrenagem na página do repositório), preencha a descrição, o site (`https://vinimarrara.github.io/NOME/`) e adicione o tópico **`portfolio`** (e outros, como `sql`, `python`, `bigquery`).

Pronto: na próxima visita o card aparece no site, com título, descrição, tags e prévia.
